Analysis I · Chapter 4 · Properties of relations

Relation properties

A relation is reflexive if every point has a loop, symmetric if every arrow has a return arrow, antisymmetric if no two different points have arrows both ways, and transitive if every path x → y → z has a shortcut x → z. Decide which properties a relation has, from its arrow diagram or from a formula, find the counterexample, sort relations into equivalence relations and orders, and work with classes and partitions. A miss pauses the clock, marks the counterexample in red, and explains itself.
